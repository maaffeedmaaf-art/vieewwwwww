# TG Stories

تطبيق أندرويد بسيط لتنزيل قصص تيليجرام باستخدام حسابك الشخصي عبر واجهة
تيليجرام الرسمية (MTProto). الواجهة عربية بالكامل.

A small Android app for downloading Telegram stories through your own
account using the official MTProto API. The UI is in Arabic.

---

## ما الذي يفعله

- ينزّل القصص النشطة و/أو المثبّتة على البروفايل لأي حساب يمكنك رؤيته.
- لا يستدعي أي طلب يسجّل المشاهدة، فلا يظهر اسمك في قائمة المشاهدين.
- يتخطّى القصص المحمية (`noforwards`) لأن الخادم لا يسمح بتنزيلها.
- يحفظ الملفات في `Download/TGStories/<اسم الحساب>/` إن سمح النظام،
  وإلا ففي التخزين الخاص بالتطبيق.

## المتطلبات

`api_id` و `api_hash` من حسابك — يُدخلان مرة واحدة داخل التطبيق:

1. افتح <https://my.telegram.org/apps>
2. سجّل الدخول برقمك (الكود يصل **داخل تيليجرام**، لا برسالة نصية)
3. املأ النموذج مرة واحدة
4. انسخ `App api_id` (رقم) و `App api_hash` (32 خانة ست عشرية)

هذه القيم خاصة بك ولا تُرفع إلى المستودع أبدًا — التطبيق يخزّنها في
`config.json` داخل التخزين الخاص بالجهاز، و`.gitignore` يمنع رفعها.

## الاستخدام

| الشاشة | الخطوة |
|---|---|
| الإعداد | أدخل `api_id` و `api_hash` |
| الدخول | رقم الهاتف برمز الدولة ← الكود ← كلمة مرور التحقق بخطوتين إن وُجدت |
| الرئيسية | `@username` ← اختر النمط ← ابدأ التنزيل |

تسجيل الدخول يحدث مرة واحدة؛ تُحفظ الجلسة في `session.txt`.

## البناء

يُبنى الـ APK تلقائيًا عبر GitHub Actions عند كل دفعة إلى `main`.
حمّله من صفحة التشغيل ← Artifacts ← `tgstories-apk`.

البناء الأول يستغرق ٤٠–٩٠ دقيقة (تجميع الـ SDK/NDK والوصفات)،
واللاحق أسرع بكثير بفضل الذاكرة المؤقتة.

مكتبتا `arabic_reshaper` و `bidi` والخط العربي تُجلب أثناء البناء ولا
تُحفظ في المستودع — راجع `.github/workflows/build-apk.yml`.

## تشخيص الأعطال

التطبيق يكتب كل شيء في `tgstories.log` داخل مجلد `Download` أو التخزين
الخاص. السطر `storage: downloads -> ...` يوضح أين تُحفظ الملفات فعليًا.

على أندرويد ١٣ فما فوق قد لا يُسمح بالكتابة في `Download`، فتذهب الملفات
إلى التخزين الخاص للتطبيق ولا تظهر في مدير الملفات. هذا سلوك متوقع.
